## 🚀 Current Projects

### 🍽️ P2P Meal Management System

I'm designing a decentralized meal-management application for small groups.

The goal is to avoid relying on a permanent central server for normal operation. Devices in a group should be able to synchronize their data directly and continue working even when internet connectivity is unavailable.

Current areas I'm exploring:

* Peer-to-peer networking
* Local-first application architecture
* Data synchronization
* Conflict resolution
* Device discovery
* QR-based group joining
* Group/member permissions
* Changing group authority
* Offline-first operation
* WebRTC data channels
* STUN/TURN as fallback infrastructure

I'm building this project partly as a practical application and partly as a way to understand **distributed systems from the ground up**.
